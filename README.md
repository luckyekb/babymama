# 🤰 BabyMama - Приложение для отслеживания беременности

Простое, доброе и бесплатное приложение для отслеживания беременности на русском языке.

## 📱 О приложении

BabyMama создано с любовью для будущих мам и пап, которые хотят отслеживать развитие малыша неделя за неделей. В отличие от других приложений на рынке, BabyMama фокусируется на простоте, доброте и полезной информации без навязчивой рекламы.

## ✨ Особенности

- 🍎 **Сравнение с фруктами**: Каждую неделю узнавайте, с каким фруктом по размеру сейчас ваш малыш
- 👶 **Информация о развитии**: Подробное описание того, что происходит с ребенком на каждой неделе
- 💝 **Изменения в теле мамы**: Что происходит с вашим телом и как к этому подготовиться
- 🏥 **Возможные симптомы**: Честная информация о том, что вы можете чувствовать
- 🥗 **Советы по питанию**: Что кушать, чтобы малышу было лучше
- 💡 **Полезные советы**: Практические рекомендации для каждой недели
- 📅 **Гибкий ввод даты**: Укажите дату последних месячных или предполагаемую дату родов
- 🔄 **Изменение даты**: Всегда можете скорректировать срок
- 📖 **Просмотр всех недель**: Листайте вперед и назад, изучайте информацию для любой недели

## 🛠 Технологии

- **Flutter** - мультиплатформенный фреймворк (iOS + Android)
- **Dart** - язык программирования
- **Provider** - управление состоянием
- **SharedPreferences** - локальное хранение данных
- **Material Design 3** - современный красивый дизайн
- **Google Fonts** - красивые шрифты

## 📦 Установка и запуск

### Требования

- Flutter SDK (3.1.0 или выше)
- Dart SDK
- Android Studio / Xcode (для запуска на эмуляторах)
- Устройство или эмулятор iOS/Android

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd babymama
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Запустите приложение:
```bash
flutter run
```

## 📱 Структура проекта

```
lib/
├── main.dart                  # Точка входа приложения
├── models/
│   └── pregnancy_week.dart    # Модель данных недели беременности
├── providers/
│   └── pregnancy_provider.dart # Provider для управления состоянием
├── screens/
│   ├── onboarding_screen.dart # Экран первого запуска (ввод даты)
│   ├── home_screen.dart       # Главный экран с текущей неделей
│   └── week_detail_screen.dart # Детальная информация по неделе
└── data/
    └── pregnancy_data.dart    # Данные по всем 40 неделям
```
